# HIM BAZ

Bilingual digital growth and technology website for HIM BAZ in the UAE.

## Setup

1. Install Node.js 22.13 or newer.
2. Copy `.env.example` to `.env.local`.
3. Add the real contact details and Google Apps Script leads endpoint locally.
4. Run `npm ci` and `npm run dev`.

Sensitive contact and form endpoint values are intentionally excluded from GitHub.
